============================================================

- 但 MD 漏掉了 app/lib/favorites-api.ts（不在 lib/api/ 目錄下，獨立檔案）

- MD 漏掉了 app/api/ 下的 56 個 Next.js API Route 檔案（MD 僅簡略提及 "Frontend proxy"）

【warranty.ts — MD 寫錯/漏掉的 function】
1. MD 寫 getDashboardStats → Code 實際是 getWarrantyDashboardStats（函式名不同）
2. Code 有 getClaimDetail → MD 漏掉此函式

【insurance.ts — MD 結構描述不精確】
1. MD 把所有 function 列為獨立 export，但 code 實際是分成 4 個 object：
   - insurancePolicyApi（getPolicies, getPolicy, createPolicy, updatePolicy）
   - projectInsuranceApi（getProjectInsurances, getProjectInsurance, createProjectInsurance, updateProjectInsurance, calculateInsurance, autoAttachInsurance）
   - insuranceClaimApi（getClaims, createClaim, updateClaim）
   - insuranceDashboardApi（getDashboardStats）
2. MD 漏掉 getProjectInsurance（單筆查詢）和 updateProjectInsurance
3. MD 寫 12 endpoints 但 code 實際有 14+ 方法（含 getProjectInsurance, updateProjectInsurance）

【material-orders.ts — MD 結構描述不精確】
- MD 列為獨立函式（listOrders, getOrder, createOrder...）
- Code 實際是 materialOrdersApi 和 shipmentsApi 兩個 object
- Code 額外有 getOrderShipments 方法（MD 漏掉）
- Code 額外有 orderUtils object（MD 漏掉）

【payments.ts — MD 結構描述不精確】
- MD 列為獨立函式（getTransactions, getTransaction...）
- Code 實際是 paymentApi object

【disputes.ts — MD 漏掉的部分】
- Code 有 disputeResolutionsAPI object（getResolution, createResolution, updateResolution）
  MD 只在 function 列表提及但沒標示為獨立 API object
- Code 有 disputeUtils object（MD 完全漏掉）

【revenue.ts — MD 漏掉的 function】
- Code 有多個 utility functions：formatCurrency, formatPercentage, getCommissionTypeLabel, 
  getParticipantTypeLabel, calculateGrowthRate（MD 完全漏掉）

【gallery.ts — MD 漏掉的部分】
- Code 有 galleryUtils object 和 handleGalleryError function（MD 漏掉）

【location-search.ts — MD 漏掉的部分】
- Code 有 locationUtils object 和 handleLocationSearchError function（MD 漏掉）

【rfq.ts — MD 漏掉的 utility functions】
- Code 有 formatBudgetRange, formatDuration, formatArea, canBidOnRfq, getTimeToDeadline
  （MD 完全漏掉）

【articles.ts — MD 描述不完整】
- MD 寫 "likeArticle, createArticle, updateArticle, getStats, getRelatedArticles"（5 個）
- Code 實際是 ArticlesApi class，有 9 個 static methods：
  getArticles, getArticleBySlug, getCategories, getPopularTags, likeArticle, 
  getStats, getRelatedArticles, createArticle, updateArticle
- MD 漏掉：getArticles, getArticleBySlug, getCategories, getPopularTags

【site-inspections.ts — MD endpoint 路徑不一致】
- MD 寫 endpoint 為 `/projects/{projectId}/inspections`（無 /api/v1 前綴）
- 其他所有 API 都有 `/api/v1/` 前綴
- Code 中確實沒有 /api/v1 前綴，所以 MD 的寫法是正確的，但格式不一致可能造成混淆

【crew-simple.ts — MD 幾乎沒有描述】
- MD 在 "Other Services" 提到 crew-simple.ts 但沒有列出任何 function

【favorites-api.ts — MD 完全漏掉】
- app/lib/favorites-api.ts 是獨立的 API 檔案
- MD 只在 endpoints.ts 的 FAVORITES_ENDPOINTS 提及 favorites
- 沒有列出 favorites-api.ts 的 function

【lib/api/client.ts — MD 漏掉】
- MD 沒有在 API file 列表提到 client.ts（API client 基礎設施）

【lib/api/index.ts — MD 漏掉】
- MD 沒有在 API file 列表提到 index.ts（統一匯出）

【projects API — MD 描述不一致】
- MD 說 /projects 頁面用 getProjects，但 code 中沒有 projects.ts API 檔案
- getProjects 呼叫可能在 ProjectsContext 或 page 內直接實作
