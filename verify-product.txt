==============================================================
A. 重要不一致（MD 寫錯或與 Code 矛盾）
==============================================================

A1. ❌ paint_product 的 material_type 預設值
    MD 寫: "fixed material_type='paint'"
    Code 實際: material_type='塗料'
    位置: app/api/products.py create_product() 第 paint_product 區塊
    影響: 文件誤導，實際用中文值 '塗料'

A2. ❌ SKU 生成格式不完整
    MD 寫: "generate SKU (SKU_{uuid[:8]})"
    Code 實際: f"SKU_{uuid.uuid4().hex[:8].upper()}"
    位置: app/api/products.py generate_sku()
    差異: MD 漏了 .upper()，實際 SKU 字母是大寫

A3. ❌ BathroomEquipment equipment query 有 runtime bug
    MD 正確寫: bathroom_equipment 沒有 installation_type（用 shape 取代）
    Code bug: products.py GET /equipment 中對 bathroom 也套用了
        bathroom_query.filter(BathroomEquipment.installation_type.in_(installation_type))
    但 BathroomEquipment model 沒有 installation_type 欄位
    影響: 當 installation_type filter 被使用時，bathroom 查詢會 runtime error
    位置: app/api/products.py query_equipment() bathroom filters 區塊

A4. ❌ DecorationProduct detail 不回傳 is_favorited
    MD 隱含 GET /products/{id} 所有類型都回傳 is_favorited
    Code 實際: area/paint/kitchen/bathroom 都傳 is_favorited，
    但 DecorationProductResponse 建構時沒傳 is_favorited 參數
    位置: app/api/products.py get_product_details() decoration 區塊
    影響: 軟裝產品 detail 頁永遠沒有收藏狀態

A5. ❌ custom_brand_name 無法透過 PUT /products/{id} 更新
    MD 寫: "Body: dict auto-cast to matching Update model" 暗示所有欄位可更新
    Code 實際: update_product() 的 base product 更新邏輯只處理:
        item_number, name, description, brand_id, origin_country,
        catalog_id, is_displayed_offline
    漏了 custom_brand_name
    位置: app/api/products.py update_product()
    影響: 廠商無法更新自有品牌名稱

C. Code 有但 MD 漏寫

C1. 📝 catalog_hashtag_queue table 未列入 Section 3 Model 清單

    Code 使用: raw SQL INSERT INTO catalog_hashtag_queue (catalog_id, catalog_type)
    位置: app/api/products.py queue_catalog_hashtag_update()
    建議: 在 Section 3 補上 catalog_hashtag_queue (catalog_id, catalog_type, created_at)

C2. 📝 私人收藏夾上限 3 個
    Code: favorites.py create_collection() 和 update_collection()
        檢查 private_collections >= 3 就拒絕
    MD Section 2.5 完全沒提到此限制

C3. 📝 brands / decoration_brands table 的 created_at / updated_at
    MD Section 3.3 brands 和 3.12 decoration_brands 的欄位表沒列出
    Code models/database.py: 兩個 table 都有 created_at / updated_at columns

C4. 📝 decoration-products 查詢支援 decoration_catalog_id filter
    Code: get_decoration_products() 有 decoration_catalog_id query param
    MD Section 2.2 decoration 查詢段落未列出此 filter

==============================================================
D. 輕微不一致（不影響功能理解）
==============================================================

D1. recommended_count 上限不一致
    MD 對 GET /products 寫 0-50
    Code: products 確實是 0-50 ✅
    但 equipment 和 decoration 各自是 0-10
    MD 沒有分別說明 equipment/decoration 的上限

D2. Redis key prefix 邏輯略不精確
    MD 寫: largehome:{env}:recommended_products:pool:{category_key}
    Code: production 時 prefix 是 "largehome:" (沒有 env 段)
         非 production 時才是 "largehome:{env}:"

D3. Blob naming 微差
    MD Section 6.1: catalogs/{brand_id}/{vendor_id}/{uuid}.pdf
    Code: blob name 是 {brand_id}/{vendor_id}/{uuid}{file_extension}
    (container 就是 catalogs，所以完整路徑一樣，只是 MD 硬寫 .pdf)

D4. move_to_products 與 move_multi_size_images 行為差異
    move_to_products: 生成新 UUID 作為 blob name
    move_multi_size_images: 保留原始 blob name
    MD 沒有區分這兩種行為，但兩者在不同場景使用

D5. decoration-products 查詢支援多分類 OR 篩選
    Code: 有 categories 參數（逗號分隔多選 OR）和 category（單選）
    MD 只描述了 category 單選

D6. decoration-products 排序支援 name 排序
    Code: sort_by 接受 composite_score/created_at/updated_at/unit_price/name
    MD 沒有列出完整的 decoration sort_by 選項
