【三、結構性問題 / 需關注事項】

1. [CRITICAL] AuditService 方法不匹配
   admin_vendors.py 呼叫 log_create/log_update/log_delete 但 audit_service.py 沒有

   recommended_vendors refresh-pool 用 raw SQL 查 paint_products table
   但 admin-service 自己沒有這個 model → 依賴 shared DB schema
