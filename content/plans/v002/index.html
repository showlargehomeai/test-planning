第二部分：認證制度

2.1 樂居 PRO 認證體系

認證品牌：樂居 PRO

🔵 PRO Basic ─── 基礎認證（藍標）
🟡 PRO Plus ──── 進階認證（金標）
🔴 PRO Elite ─── 戰略認證（紅標）

核心設計理念：

  • 付的不是「月費」，是「認證維護費」
  • 沒認證 = 不是 PRO = 功能受限
  • 認證標章 = 行業身份象徵
  • 認證客戶優先配對，形成「圈內人經濟」

轉換話術（從「收費」到「認證」）

❌ 舊話術（月費思維）：

"我們平台要開始收費了，月費$10,000，可以使用這些功能..."

✅ 新話術（認證思維）：

"我們推出了樂居PRO認證制度。通過認證的建材商，會獲得認證標章，在平台上優先被200+認證設計師看到。認證需要審核您的產品品質、回覆速度，不是每家都能通過。認證維護費$10,000/月。您有興趣申請嗎？"

心理差異：

  • 月費：你向我要錢 → 抗拒
  • 認證：我想向你申請 → 主動

3.2 BD 全循環工作模型

一個BD做全循環（不分供給BD和CS）

① 開發客戶 (40%) → ② 讓客戶成功 (30%) → ③ 發現瓶頸 (10%) 
    ↑                                              ↓
⑤ 閉環回訪 (10%) ← ④ 反饋產品團隊 (10%) ←────────┘

為什麼一個人做全循環？

  1. 開發客戶的人最了解客戶痛點
  2. 客戶不用跟兩個人重複講一樣的話
  3. BD看到客戶成功才有動力做好
  4. BD自己反饋的需求被產品實現，能回去跟客戶說「搞定了」

3.3 BD 各階段職責

階段 BD 做什麼 時間佔比 關鍵產出
① 開發客戶 拜訪建材商+工班，用「加速工作」切入 40% 新註冊用戶
② 讓客戶成功 教客戶用平台、追蹤使用狀況 30% 活躍用戶、成功連結
③ 發現瓶頸 觀察客戶卡住的地方 10% 瓶頸清單
④ 反饋產品 填需求工單、提交產品反饋組 10% 需求工單
⑤ 閉環回訪 產品改善後回去告知客戶 10% 客戶滿意度UP

總結

成功關鍵要素

  1. 精準定位：工作加速器，不是撮合平台
  2. 認證心理：付費變成「申請認證」，心理門檻降低
  3. 全循環BD：開發+成功+反饋+閉環，確保客戶留存
  4. 產品閉環：客戶需求→產品改善→客戶更成功→更黏平台
  5. 現金流控制：M5前必須開始盈利

致勝策略三要件

  1. 速度：搶在競品前建立市場地位
  2. 深度：不只做交易撮合，做工作流程優化
  3. 黏性：透過認證制+需求反饋建立客戶依賴

這是一個「先建生態，再變現」的策略。關鍵是Phase 1跑通連結，Phase 2成功轉認證制，Phase 3實現規模盈利。
