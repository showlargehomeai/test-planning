🔬 三、BD 專精化分析 — 產品×工項×區域深耕策略

核心理念：每個 BD 像房仲一樣深耕自己的「區域×品類」。
不是一個 BD 跑全台所有品類，而是讓每個 BD 成為「大安區磁磚專家」「台中衛浴達人」。
越深耕 → 越了解客戶 → 成交率越高 → 客戶黏著度越強 → 轉介紹越多。

  • 建材商有新品 → 第一時間告訴 BD
  • 工班有問題 → 找 BD 協調
  • 這種關係是時間壁壘，新進者需要 2-3 年才能追上

🔄 飛輪四段引擎

① 公司設規範 → ② BD 依規範找資源
↑ ___________________________ ↓
④ 數據回饋優化規範 ← ③ 客戶得到服務

① 公司設規範（總部）

  • 建材商上架標準（照片規格、價格格式、描述模版）
  • 工班認證標準（作品集、證照、評價門檻）
  • BD 拜訪 SOP（話術腳本、demo 流程、CRM 填寫規範）
  • 定價方案與折扣權限（BD 可自行決定的範圍）
  • 規範 = 可複製的成功公式

② BD 依規範找資源（現場）

  • 按品類 checklist 掃街（確保不漏掉主力品牌）
  • 按拜訪 SOP 標準化開發（每個 BD 的話術一致）
  • 建材商上架時用標準模版（品質一致）
  • 工班註冊時驗證資格（確保服務品質）
  • 規範讓新人 2 週就能上手，不依賴個人英雄

③ 客戶得到服務（市場）

  • 設計師搜建材 → 品項齊全、價格透明、一鍵詢價
  • 設計師找工班 → 有評價、有作品、有認證
  • 建材商獲客 → 設計師主動來搜、詢價量成長
  • 工班接案 → 不用被動等電話、案源穩定
  • 每個角色都「工作變快、賺更多」→ 口碑傳播

④ 數據回饋優化規範（閉環）

  • BD 反饋：「客戶說搜尋不夠準」→ 產品改善搜尋
  • 數據顯示：「磁磚詢價量最高」→ 加派磁磚 BD
  • 客戶流失：「衛浴品項太少」→ 補齊衛浴供給
  • 成交數據：「大安區轉化率最高」→ 該區 BD 加倍
  • 數據驅動決策，不靠猜

為什麼能指數成長？

1. 平台的傳播力：建材商上架 → 設計師來搜 → 設計師告訴其他設計師 → 更多設計師 → 更多建材商想上架。

2. SOP 的複製力：台北打版的話術/流程/demo 腳本 → 直接搬到台中用。
新人不需要從零摸索，照 SOP 走 2 週就能開始簽約。這就是「規範」的力量。

3. 數據的累積力：每多一個建材商 → 價格資料庫更完整 → 比價功能更好用 → 更多設計師來 → 更多建材商想上。
這個數據飛輪一旦轉起來，後進者需要 3 年才能追上你 3 個月累積的數據量。

🛒 五、設計師採購聯盟 — 樂居的終極護城河

👑 武器 3：團購議價 / 平台獨家價

這個功能不需要寫 code，需要的是 BD 拿數據去談。
