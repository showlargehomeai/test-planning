🏗️ 三、BD 組織架構 — 雙軌制落地方案

核心決策：採用「混合獵人 + 專精農夫」雙軌制
200BD 全台擴張計畫的規模 × BD 角色規劃方案的「全循環」理念 = 混合雙軌制。
混合 BD 快速覆蓋市場、專精 BD 深度經營高價值客戶。

🦁 混合獵人 BD（111人）— 60% 主力

定位：按區域劃分，同一天跑同一區所有類型客戶

核心優勢：建材商和工班互為線索來源，一次拜訪通吃三角色

日常節奏：

  • 上午：拜訪設計公司 → 順帶簽設計師 → 拿到建材商/工班線索
  • 下午：拜訪建材行 → 邀請上架 → 認識配合工班
  • 傍晚：更新 CRM + 轉介紹給專精 BD

月 KPI：≥60 積分（多維度計分，跨類型轉介紹加分）

月收入：$43K（新人）→ $55K（達標）→ $85K+（頂尖）

🐂 專精農夫 BD + CS（89人）— 40%

建材專精 BD（29人）：深度簽約、產品上架輔導、續約經營、付費升級

設計師成功 CS（36人）：不是「賣」而是「教」— 教育訓練、社群經營、付費轉換

SDR（24人）：線索開發、電話預約、漏斗頂部

CS 與供給 BD 的協作飛輪：

  1. CS 收集設計師需求（「設計師在找 XXX 建材」）
  2. 供給 BD 優先開發該建材廠商
  3. 建材商上架 → CS 推播給設計師
  4. 設計師：「這平台越來越好用！」→ 🔄 正向循環

Phase 2：M3-M5 北部全面展開 + 中南啟動

🟡 +80-100 人 → 公司達 130-150 人

  • 北部 BD 衝到 40-50 人（混合獵人為主）
  • 中南部 VP 到位、每區先進 10-15 BD
  • SDR 團隊啟動（每區 5-8 人）
  • 第一批 BD 開始成交 → 月新簽 ≥90 客戶
  • M5：全平台宣布樂居 PRO 認證制度
  • Phase 1 免費版 → 開始限縮功能，引導升級
⚡ 這是現金流壓力最大的階段。人事成本快速膨脹但營收還沒跟上。
需要 1.5 億以上銀行額度作為安全網。
Gate 2（M5 底）：月新簽 ≥90 客戶 + 3 個辦公室運轉 → GO
月新簽 <60 → 凍結招聘，診斷問題。
Phase 3：M6-M9 全台加速 + 認證變現

🟢 +120-140 人 → 公司達 270-300 人

  • 全面衝量：北部 70-80 BD，中南部各 30-40 BD
  • 東部據點啟動（M5 起）
  • M6：推出 PRO Basic 認證（首月 5 折）
  • M7：建材商基礎版 $10K/月上線
  • M8：設計師基礎版上線
  • M9：工班基礎版上線
  • Hunter/Farmer 正式分流
  • CS 團隊全面運轉 → 設計師留存率 >75%
🎯 M6-M7 是關鍵轉折點：SaaS MRR 超過人事成本，正現金流開始。
Gate 3（M8 底）：月新簽 ≥250 + MRR >2,000 萬 + 現金流正 → GO
MRR <1,500 萬 → 目標收縮到 100 BD 穩住。
Phase 4：M10-M12 補齊 + 升級 + 穩固

🔵 +50-60 人 → 公司達 380-420 人

  • 補齊 200 BD 缺口
  • M10+：推出 PRO Plus 進階認證（建材商 $30K、設計師 $30K、工班 $10K）
  • 績效評估全面展開：淘汰 15-20% 並補新血
  • 月度 Business Review 制度化
  • 開始規劃 2027 年 100→300 BD 架構
Final Gate（M12）：200 BD + MRR >5,000 萬 + 全台 4 區域運轉 ✅

🔑 產品 × BD 協作機制（閉環反饋）

BD 現場收集需求 → 需求工單（3分鐘） → 產品反饋組整理分類
↓
每週五「需求評審會」（BD主管 + PM + 反饋組）
↓
產品排入開發（P0:48hr / P1:1週 / P2:月度）
↓
上線後通知 BD → BD 回去跟客戶說「改好了」 → 🔄 客戶黏著度 UP

每個 BD 每月必須提交 ≥5 則需求工單。需求被採納額外獎金 $1,000。
反饋得越多 → 產品越好 → 留存越高 → BD 工作越輕鬆。

  1. 招聘品質失控（月均33人）→ 標準化4關面試 + 90天嚴格淘汰
